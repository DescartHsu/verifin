## 本版变化

- 新增 Windows x64 电脑版，与 Android 共用首页、资产、看板和记账编辑页。首次连接会载入手机账本和布局。
- 手机首页右上角可直接扫码配对。授权全部账本后，账本切换、预算、多币种流水、票据图片及布局会在同一局域网内双向同步。
- 修复扫码后停在「等待同步」。电脑保存修改后，手机打开 Veri Fin 并解锁就会自动接收。离线修改会在重新连接后补同步，同一条记录发生冲突时可在手机上选择保留的版本。

## 安装与连接

- **Android 手机**请下载 arm64 APK，直接覆盖安装原来的正式版。升级前可在「数据管理」导出备份。使用「Veri Fin 图形诊断」的用户请先从诊断版导出备份，再在正式版中导入，两者使用独立的数据目录。
- **Windows 电脑**请下载 Windows x64 ZIP，退出旧电脑版，将新版完整解压到新文件夹，运行 `verifin_desktop.exe`。
- 电脑接网线、手机连同一路由器的 Wi-Fi 即可。首次使用时在电脑点「连接手机」，用手机首页右上角扫码。已有配对可以在手机同步页点「授权同步全部账本」。
